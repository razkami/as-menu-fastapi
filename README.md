# As мәзірі

Қазақ тіліндегі оқу веб-сервисі: FastAPI сервері, SQLite дерекқоры және JavaScript интерфейсі.

## Мүмкіндіктер

- Клиент беті: тағам іздеу, санат каруселі, JavaScript сүзгісі және сұрыптау.
- Тағамды ас уақытына қосу, порцияны өзгерту және тәуліктік энергия/ақуыз/май/көмірсу сомасын есептеу.
- Тіркелу, жүйеге кіру және күндік мәзірді сақтау.
- Әкімші беті: тағамды қосу, өңдеу, жасыру және қайта қосу.
- Серверлік рөл тексеруі, HttpOnly сессия cookie, CSRF тексеруі, PBKDF2 құпиясөз хэші.
- SQLite кестелері: users, foods, menus, menu_items.

## PyCharm-та іске қосу

1. PyCharm-та Open арқылы осы буманы ашыңыз.
2. Python 3.11+ интерпретаторын және виртуалды ортаны таңдаңыз.
3. PyCharm Terminal ішінде орындаңыз:

   python -m pip install -r requirements.txt
   python -m app.create_admin
   python -m uvicorn app.main:app --reload

4. Әкімшінің поштасы мен құпиясөзін енгізіңіз. Құпиясөз терминалда жасырылып жазылады.
5. Клиент: http://127.0.0.1:8000
6. Әкімші: http://127.0.0.1:8000/admin
7. API құжаттамасы: http://127.0.0.1:8000/docs

Қажет болса PyCharm Run Configuration ортасына APP_SECRET_KEY мәнін орнатыңыз. Өндірісте APP_ENV=production, жеке құпия кілт және HTTPS қолданыңыз; HTTPS кезінде COOKIE_SECURE=true орнатыңыз.

Бірінші іске қосылғанда 16 демонстрациялық тағам енгізіледі. Мәндер оқу мақсатына арналған: нақты тағам жапсырмасын тексеріңіз. Сервис медициналық кеңес бермейді. Дерекқор data/nutrition_menu.db ішінде сақталып, Git-ке қосылмайды.
